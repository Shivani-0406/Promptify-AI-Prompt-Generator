# Promptify – AI Prompt Generation System

Promptify is an AI prompt generation system that collects user requirements through Google Forms and generates customized prompts for different AI tasks.

## Features

- Google Form input
- Google Sheets data storage
- Task-specific prompt generation
- Image prompt generation
- Code prompt generation
- PowerPoint prompt generation
- Resume prompt generation
- Generated prompt history

## Technologies Used

- Google Forms
- Google Sheets
- Google Apps Script
- JavaScript

## How It Works

User
↓
Google Form
↓
Google Sheet
↓
Google Apps Script
↓
Prompt Engine
↓
Generated Prompt
↓
Prompt History
